# 출시 체크리스트 (폰으로 할 수 있는 것 위주)

## 0. 지금 폰에서 테스트하기
1. GitHub 앱/웹 → 이 저장소 → **Actions** → 최신 "Android build" 실행 → 아래 **Artifacts** 에서
   `onetouch-cleaner-debug-apk` 다운로드 → 압축 풀고 APK 설치
2. 앱 실행 → '권한 켜기' → 접근성에서 '원터치 클리너' 켜기
   - Android 13+ 에서 "제한된 설정" 이라고 막히면:
     설정 → 애플리케이션 → 원터치 클리너 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 다시 켜기
     (Play 스토어로 설치한 경우엔 이 단계가 없습니다)
3. 디버그 빌드는 **테스트 광고**가 나옵니다(정상).
4. 잘 안 되는 앱/기기가 있으면 기종 + 안드로이드 버전 + 어디서 멈췄는지 알려주세요.

## 1. Google Play 개발자 계정 (폰 가능)
- https://play.google.com/console → 개인 계정 등록, 등록비 $25, 신분증 인증
- ⚠️ **2023-11 이후 만든 개인 계정은 프로덕션 출시 전 '비공개 테스트'에
  테스터 12명 이상이 14일 연속 참여**해야 합니다. 지인 12명을 미리 모아두세요.

## 2. AdMob (폰 가능)
1. https://admob.google.com → 앱 추가(Android, "아직 스토어에 없음")
2. 광고 단위 → **보상형(Rewarded)** 생성
3. 앱 ID(`ca-app-pub-…~…`)와 광고 단위 ID(`ca-app-pub-…/…`)를
   GitHub 저장소 → Settings → Secrets and variables → Actions 에 등록:
   - `ADMOB_APP_ID`, `ADMOB_REWARDED_ID`
4. 스토어 출시 후 AdMob에서 앱을 Play 스토어 앱과 연결
5. 사업자/개인 정산 정보, `app-ads.txt` 는 출시 후 설정

## 3. 업로드 키 (서명키) — PC가 있으면 가장 쉬움
Play 에 올리는 AAB 는 업로드 키로 서명해야 합니다. GitHub Secrets 에 4개 등록:
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
→ 등록되면 Actions 가 자동으로 `onetouch-cleaner-release-aab` 를 만들어 줍니다.
(키 파일은 절대 분실/공유 금지. 분실 시 Play Console 에서 업로드 키 재설정 요청 가능)

## 4. Play Console 앱 만들기
- 앱 이름: 원터치 클리너 / 기본 언어: 한국어 / 앱 / 무료
- **패키지명 `com.saker900.onetouchcleaner` 은 첫 업로드 후 변경 불가** — 바꾸려면 지금 말해주세요.

### 앱 콘텐츠 항목 답변
| 항목 | 답변 |
|---|---|
| 개인정보처리방침 | `PRIVACY_POLICY.md` 를 공개 URL로 게시 (GitHub Pages 등) |
| 광고 포함 | 예 |
| 앱 액세스 권한 | 모든 기능 제한 없이 이용 가능 (로그인 없음) |
| 콘텐츠 등급 | 설문 → 유틸리티, 폭력/선정성 등 모두 '아니요' → 전체이용가 |
| 타겟층 | 18세 이상 권장 (아동 대상이면 광고 규정이 훨씬 까다로움) |
| 데이터 보안 | 수집: 기기 또는 기타 ID(광고 ID) — AdMob, 목적: 광고·분석. 앱 활동/구매 내역 — Google Play 결제. 전송 중 암호화: 예. 삭제 요청: 이메일 |
| 광고 ID | 사용함 (광고) |
| **접근성 API 선언** | 아래 참고 |

### 접근성 API 선언 (가장 중요, 거절 위험 1순위)
Play Console → 앱 콘텐츠 → '민감한 앱 권한' → AccessibilityService API
- 핵심 기능 설명 예시:
  > 사용자가 '정리 시작' 버튼을 누를 때에만, 사용자가 직접 선택한 앱들의 시스템 '앱 정보' 화면을 열어
  > '강제 종료'와 '캐시 지우기' 버튼을 사용자를 대신해 누릅니다. 안드로이드는 일반 앱이 다른 앱을 종료하거나
  > 캐시를 삭제하는 API를 제공하지 않으므로 접근성 API가 이 기능의 유일한 방법입니다.
  > 화면 데이터는 수집·저장·전송하지 않습니다. 앱은 접근성 도구가 아니며 isAccessibilityTool=false 로 선언했습니다.
- **시연 동영상(YouTube 링크) 필수**: ① 앱 내 고지 화면 → 동의 ② 접근성 켜기 ③ 정리 시작 → 자동 종료/캐시 삭제
  화면 녹화(폰 기본 화면 녹화) 후 YouTube '일부 공개'로 업로드
- 앱 내 '명시적 고지 + 동의' 다이얼로그는 이미 구현되어 있습니다.

## 5. 인앱 상품 (광고 제거 ₩5,900)
Play Console → 수익 창출 → 제품 → 인앱 상품 → 만들기
- 제품 ID: **`remove_ads_lifetime`** (코드와 정확히 일치해야 함)
- 이름: 광고 평생 제거 / 가격: ₩5,900 / 활성화
- 결제 프로필(판매자 계정) 먼저 만들어야 함
- 인앱 상품은 AAB 를 한 번 업로드(테스트 트랙)한 뒤에 만들 수 있습니다.
- 라이선스 테스터에 본인 Gmail 추가 → 실제 결제 없이 구매 테스트 가능

## 6. 스토어 그래픽
- 아이콘 512×512, 그래픽 이미지 1024×500: `docs/store-assets/` 에 생성해 둠
- 스크린샷: 실제 폰에서 2~8장 캡처 (가짜 화면 금지)

## 7. 출시 순서
내부 테스트 → 비공개 테스트(12명·14일) → 프로덕션 신청
