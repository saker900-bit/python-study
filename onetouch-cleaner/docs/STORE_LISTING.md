# Play 스토어 등록정보 (복사해서 붙여넣기용)

## 앱 이름 (30자 이내)
원터치 클리너 - 앱 종료 & 캐시 정리

## 간단한 설명 (80자 이내)
버튼 한 번으로 선택한 앱을 강제 종료하고 캐시를 지워요. 제외할 앱도 고를 수 있어요.

## 자세한 설명
설정 → 애플리케이션 → 앱마다 들어가서 '강제 종료', '캐시 지우기'를 누르던 귀찮은 작업을
원터치 클리너가 버튼 한 번으로 대신 해드립니다.

■ 주요 기능
• 원터치 정리: 선택한 앱을 한 번에 강제 종료
• 캐시 삭제: 각 앱의 임시 파일(캐시)도 함께 삭제 (끄기 가능)
• 적용/제외 선택: 정리할 앱과 건드리지 않을 앱(메신저, 음악 등)을 직접 선택
• 시스템 앱은 기본 제외 – 필요한 것만 골라서 적용
• 앱 검색, 전체 적용/전체 제외

■ 이용 방법
1. 처음 실행 시 안내에 따라 '원터치 클리너' 접근성 서비스를 켭니다.
2. 목록에서 정리할 앱을 체크합니다. (체크 해제 = 제외)
3. '정리 시작'을 누르면 자동으로 정리됩니다.

■ 광고 및 광고 제거
• 무료 버전은 정리할 때마다 짧은 광고를 1회 시청합니다.
• '광고 평생 제거'(₩5,900, 1회 결제)를 구매하면 광고 없이 바로 실행됩니다.
• 같은 Google 계정이면 재설치·기기 변경 후에도 자동 복원됩니다.

■ 접근성 서비스(AccessibilityService API) 사용 안내
이 앱은 사용자가 '정리 시작'을 누를 때에만, 선택한 앱의 '앱 정보' 화면에서
'강제 종료'와 '캐시 지우기' 버튼을 사용자 대신 누르기 위해 접근성 서비스를 사용합니다.
화면 내용·개인정보·입력 내용을 수집하거나 전송하지 않습니다.

■ 참고
• 기기 제조사/안드로이드 버전에 따라 일부 앱은 처리되지 않을 수 있습니다.
• 강제 종료된 앱도 알림·예약 작업 등으로 다시 실행될 수 있습니다. (안드로이드 정상 동작)
