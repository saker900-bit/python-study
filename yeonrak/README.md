# 연락각 📞

"이쯤 되면 연락 한번 해줘야지" 를 알려주는 앱. 연인, 배우자, 부모님, 친구와 연결해서 쓴다.

## 기능
- **연락 타이머**: 상대마다 연락 텀(예: 연인 6시간, 엄마 3일)을 정해두면, 넘었을 때 양쪽에 "연락할 각 ⏰" 알림.
- **📞 연락했어요**: 누르면 타이머 초기화 + 상대에게 "연락 왔어요" 알림.
- **📢 야 연락 안 하냐?**: 연결된 상대에게 재촉 푸시 (10분에 한 번).
- **🤔 왜 연락이 없지?**: 지금 시각·요일, 상대가 남긴 상태(회식 중 등), 평소 연락 시간대를 보고
  AI가 안심 멘트를 만들어줌. 예) "금요일 밤 11시예요. 아마 술 한잔하느라 폰 볼 틈이 없나 봐요 🍻"
  - `ANTHROPIC_API_KEY` 가 있으면 Claude, 없으면 규칙 기반 멘트.
- **내 상태**: "회식 중", "운동 중" 같은 상태를 남기면 상대 쪽 AI가 참고.

## 실행
```bash
cd yeonrak
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...   # 선택
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
휴대폰 브라우저로 `http://<서버주소>:8000` 접속 → 이름 입력 → 초대 코드를 상대에게 공유 → 상대가 "새 상대 연결하기"에 코드 입력.
"🔔 알림 켜기"를 누르면 브라우저 알림으로 받는다 (앱이 열려 있거나 백그라운드에 있을 때 15초마다 확인).

환경 변수: `YEONRAK_DB` (DB 파일, 기본 `yeonrak.db`), `YEONRAK_TZ` (기본 `Asia/Seoul`),
`YEONRAK_CHECK_SEC` (리마인더 확인 주기, 기본 60), `YEONRAK_MODEL` (기본 `claude-opus-5-5`).

## 테스트

cd yeonrak && python -m pytest -q

## 안드로이드 앱 (APK)
`android/release/yeonrak.apk` — 서버 없이 폰 한 대로 바로 쓰는 버전 (안드로이드 8 이상).
- 챙길 사람 등록 → 연락 텀이 지나면 앱이 꺼져 있어도 안드로이드 알림
- 📢 야 연락 안 하냐? → 카톡 등으로 재촉 메시지 보내기 (공유 창)
- 🤔 왜 연락이 없지? → 시간대·요일·상대 일정·평소 연락 시간으로 안심 멘트 (폰 안에서 규칙 기반)

다시 빌드: `android/build.sh` (안드로이드 SDK 없이 JDK + python3 + Maven Central 만으로 빌드).
서명 키는 `android/build/` 에 매번 새로 만들어지므로, 새 빌드를 설치할 땐 기존 앱을 지우고 설치해야 한다.
