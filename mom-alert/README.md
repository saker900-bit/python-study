# 📡 엄마레이더 (Android)

백그라운드에서 다가오는 **발소리(마이크)** 와 **바닥 진동(가속도 센서)** 을 감지해서
진동 + 푸시 알림 **"엄마떴다!"** 로 알려주는 앱.

## 동작 방식
- **발소리**: 마이크 소리 중 300Hz 아래 저음(쿵쿵)의 크기만 32ms마다 계산. 주변 소음보다 갑자기 커지면 "충격 1번".
- **진동**: 폰이 바닥/책상에 놓여 있을 때 가속도 센서의 미세한 떨림을 봄. 손에 들고 있으면 자동으로 쉼.
- **걸음 판정**: 충격이 0.25~1.6초 간격으로 N번(기본 3번) 이어지면 걸음으로 판단.
  "점점 커질 때만" 옵션을 켜면 소리가 커지는(다가오는) 경우에만 알림.
- 알림은 **소리 없이 진동만** (들키지 않게). 한 번 울리면 15초 쉼.
- 소리는 녹음·저장·전송하지 않음.

## 테스트 APK 받기
1. GitHub 레포 → **Actions** 탭 → "엄마레이더 Android 빌드" → 가장 최근 성공한 실행
2. 아래 **Artifacts** 의 `mom-radar-debug-apk` 다운로드 → 압축 풀면 `app-debug.apk`
3. 폰에서 열어 설치 ("출처를 알 수 없는 앱" 허용 필요)

## 테스트 요령
1. 앱에서 **🔔 알림 테스트** 로 진동/알림이 오는지 먼저 확인
2. **감시 시작** → 화면에 실시간 수치가 나옴. 누가 걸어올 때 `걸음 1, 2, 3…` 이 올라가는지 확인
3. 안 잡히면 감도를 올리고, 오작동이 잦으면 감도를 내리거나 "몇 걸음"을 늘리기
4. 홈으로 나가서 다른 앱을 써도 계속 감시됨 (상단에 "감시 중" 알림이 떠 있음)

### 주의
- 게임/영상 소리가 스피커로 나오면 마이크가 그걸 발소리로 착각할 수 있음 → **이어폰 권장**
- 통화·녹음 등 다른 앱이 마이크를 쓰면 발소리 감지가 멈춤
- 삼성 등 일부 폰은 배터리 최적화로 앱을 죽일 수 있음 → 설정 > 앱 > 엄마레이더 > 배터리 > **제한 없음**
- 안드로이드 8.0 이상

## 스토어 출시 준비
